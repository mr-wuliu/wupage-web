2. 服务内容与第三方依赖

WuPage 提供网页、选中文字、图片识别文字及 PDF 文字的翻译与阅读辅助功能。具体功能及兼容性以您安装的扩展版本为准。

在线翻译由您选择或配置的第三方服务提供，包括 Microsoft、Google、DeepSeek、智谱 GLM 等；第三方可能调整接口、额度、价格或可用性。选择本地翻译并准备好模型后，相应翻译任务在本机处理。

扩展基础功能可免费使用。您自行购买的第三方 API 服务由您与相应供应商直接结算，不属于向我们的付款。

3. 设置、凭据与使用安全

现有扩展功能无需注册 WuPage 账户。请妥善保管浏览器配置、API 密钥和付款凭证，并仅配置可信的服务地址。使用第三方服务时，须遵守该服务的条款。

请勿在公开反馈中提交密钥、支付卡信息或含敏感内容的日志。如发现与 WuPage 有关的安全问题，请通过本页邮箱联系我们。

4. 一次性自愿支持付款

您可以在我们提供支持付款入口时，自愿支付一笔金额以支持项目维护与开发。金额、币种及适用税费以结账页面最终确认的信息为准；请在确认前核对。

每笔支持付款均为独立的一次性交易，不是订阅，不自动续费或自动充值，也不建立积分、储值余额或可提现资产。后续支持须由您再次主动确认付款。

支持付款不构成慈善捐赠，不承诺税收抵扣、投资回报、专属功能或特定开发进度；未付款不影响现有免费功能的使用。

5. 付款授权与支付处理

您确认结账即授权支付处理方向您选择的支付方式收取该笔交易显示的金额，不代表授权后续周期扣款。第三方可能收取汇兑或银行费用，以其规则为准。

通过 Waffo Pancake 收银台完成的交易，由 Waffo Pancake 及其支付合作方处理。支付卡资料由支付处理方处理，我们不接收或保存完整卡号及卡片安全码。我们可能获得对账、支持和退款所需的订单编号、付款邮箱、金额、币种、时间及支付状态。

6. 取消与停止支持

付款完成前，您可以直接退出结账流程。付款完成后，如需撤销该笔支持，请依下一节申请退款。由于没有周期订阅，您无需取消订阅；不再发起付款即可停止后续支持。

停止支持不会自动删除您浏览器中的设置或缓存。清除本地数据的方法见隐私政策中的存储说明。

7. 退款与账单争议

自一次性支持付款完成之日起 7 个日历日内，您可申请该笔付款的全额退款。超过 7 天的申请，我们将结合交易情况处理；适用法律赋予的退款、撤销及消费者权利不受本条限制。

确认的重复扣款、错误扣款或未经授权的交易，可申请退款，不受上述 7 天窗口限制。若仅显示扣款处理中，请一并提供状态以便核查。

请发送邮件至 master.wuliu@gmail.com，注明付款邮箱、订单或交易编号、付款日期、金额及退款原因，无需提供完整卡号、密码或安全码。我们将在 2 个工作日内回复，并在核实后 5–10 个工作日内向支付处理方提交符合条件的原路退款；实际到账时间取决于支付机构及银行。

如对扣款有疑问，欢迎先联系我们核对；这不限制您依法向银行、支付机构或主管部门提出争议的权利。第三方 API 费用请向相应服务商申请处理。

您允许本服务仅为完成所请求的功能处理必要内容。我们不将您的输入或输出用于训练 AI 模型。在线服务商的数据使用方式由其政策决定，请在提交敏感材料前查阅。
