无需密钥，先试一次

Google Web Translate

这是默认启用的服务。回到弹窗选择 Google Web Translate，点击「翻译全文」即可。若无法使用，检查网络或切换其他服务。

使用已有的 AI 账户

DeepSeek

在 DeepSeek 平台创建 API Key，在 WuPage 设置中选择 DeepSeek，粘贴密钥并选择账户可用的模型。保存后，回到弹窗选择这项服务。

打开 DeepSeek 平台 ↗

选择熟悉的 AI 服务

智谱 GLM

登录智谱开放平台，在「API Key」中创建并复制密钥。打开 WuPage 设置，选择 GLM 服务，填写密钥及账户可用的模型，保存后在弹窗中选择使用。

打开智谱开放平台 ↗

下载模型，离线阅读

Firefox 本地翻译（实验）

Chrome、Edge 也能使用，无需安装 Firefox。在设置中选择此服务，按提示下载所需语言方向的模型，等到「模型已就绪」再翻译。非英语之间通常需要同时准备两个经英语中转的方向。

模型按语言方向下载，每个约 35–55 MB，以设置页显示为准。下载可暂停和继续，也支持离线导入。模型就绪后，文字在本机处理；运行时会增加内存、耗电和存储占用。暂不支持韩语与繁体中文。
使用 Azure 翻译账户

Microsoft Translator

在 Azure 创建 Translator 资源，将资源的密钥和所需区域填入 WuPage 的 Microsoft Translator 设置，保存后在弹窗中选择使用。

使用 Google Cloud 账户

Google Cloud Translation

在 Google Cloud 启用 Cloud Translation API 并创建 API Key，将密钥填入 WuPage 的 Google Cloud Translation 设置。服务商可能要求开通结算。

使用你已有的服务

其他 AI 与本地服务

在设置中添加 OpenAI Compatible 或 Anthropic Compatible 服务，填写服务商提供的服务地址、模型和所需密钥。也可连接兼容的本地服务。
